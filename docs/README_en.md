## Why did I build this?

I wanted a simple chat with Ollama directly from the terminal, without graphical intermediaries.
OpenWebUI felt too heavy for what I needed, and Ollama's native chat is functional but visually unappealing and uncomfortable to use. So I decided to build something that was direct, colorful, and enjoyable to use without leaving the terminal.

# LLM-Chat

A command-line client written in Go to chat with models hosted locally via [Ollama](https://ollama.com). A simple terminal client that supports multimodal inputs and context management.

[![llmchat.gif](https://i.postimg.cc/fLjF5PW7/llmchat.gif)](https://postimg.cc/tZJ242x7)

## Requirements

- Go 1.25 or higher (defined in `go.mod`).
- [Ollama](https://ollama.com/download) installed and accessible in the system PATH (the server can also run remotely).
- At least one model downloaded in Ollama that supports the desired modality (text, images, etc.).
- A terminal that supports ANSI sequences (on Windows, the binary itself enables virtual terminal mode upon startup).

## 1. Setting up the Ollama Server

The client does not start Ollama itself: it only connects to a server that must already be running.

1. Install Ollama following the official guide for your operating system.
2. Start the server:

   ```bash
   ollama serve
   ```

   By default, Ollama listens on `127.0.0.1:11434`. If you have already installed it as a system service, it might already be running in the background, and this step may not be necessary.

3. Download at least one model (in another terminal, with the server already running):

   ```bash
   ollama pull llama3
   ```

   You can replace `llama3` with any model available on [ollama.com/search](https://ollama.com/search).

4. Verify that the server is responding:

   ```bash
   curl http://localhost:11434/api/tags
   ```

   If it returns a JSON list of models, the server is ready for the client to connect.

## 2. Compiling the Client

Clone the repository and compile with Go:

```bash
git clone https://github.com/Urban20/LLM-Chat.git
cd LLM-Chat
go build .
```

This generates an executable binary `llm-chat` (or `llm-chat.exe` on Windows) in the current directory.

## 3. Running the Client

Basic execution, assuming Ollama runs on `localhost:11434`:

```bash
./llm-chat
```

### Available Flags

| Flag       | Default Value | Description                                              |
|------------|---------------|-----------------------------------------------------------|
|`-h`        | *empty*       | displays help                                             |
| `-host`    | `localhost`   | Host/URL where the Ollama endpoint is listening.         |
| `-puerto`  | `11434`       | Port of the Ollama endpoint.                             |
| `-ctx`     | `16000`       | Context capacity (tokens) that the LLM will use. **Note:** This limit now includes tokens generated by attached documents.|
| `-temp`    | `0.5`         | Model temperature (creativity of responses).          |
| `-o`       | `false`       | Saves the answers to a Markdown file (`.md`) upon session completion. |

**Advanced Example:** Pointing to a remote server with large context, low temperature, and saving results:

```bash
./llm-chat -host 192.168.1.50 -puerto 11434 -ctx 32000 -temp 0.2 -o
```

## 4. Using the Client

Upon starting, the program performs the following checks:

1. Verifies if Ollama is in the system environment variables (warns if it cannot find it, but continues).
2. Verifies that the server responds at the configured URL.
3. Lists the models already downloaded on the server. If none are found, it will ask you to run `ollama pull (model)` and terminate execution.
